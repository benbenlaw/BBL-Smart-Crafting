Changelog BBL Smart Crafting Table 

# 2.0.0
- Updated to minecraft 26.1.2
  FTB Chunks integration, Curios support, config list of allowed storage blocks,
  Stonecutter must be nearby for stonecutter recipes, shift crafting only fills free inventory space,
  Russian, Japanese and Chinese translations
- Fixed sort mode and favorites not being remembered
- Fixed recipes not working on dedicated servers
- Added smithing table support (needs a smithing table nearby, range is configurable)
- Added crafting, stonecutting and smithing sounds
- Added recursive crafting, crafts intermediate items for you (logs -> planks -> stairs), toggled with a new button
- Added GUI option buttons, search bar and title swapped, JEI search sync
- Config: recursiveCraftingEnabled, recursiveCraftingMaxDepth, smithingTableRangeCheck
- No longer requires BBL Core
- Portable Smart Crafting Table hotkey is now validated on the server
